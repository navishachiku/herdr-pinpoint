คุยข้าม pane ใน Herdr นี่เจ๋งมาก แต่เคยรู้สึกไหมว่าอธิบายเป้าหมายทีไรเสียเวลาทุกที?
โดยเฉพาะตอนที่มันอยู่คนละ Space

เป้าหมายที่คลุมเครือมีต้นทุนสองต่อ: token ของคุณที่ใช้อธิบาย และ token ของ agent
ที่ใช้ไปตามหา ป๊อปอัปนี้ตัดทั้งสองอย่างออก

> แค่สามวินาทีก็ระบุเป้าหมายได้ เร็วกว่าพิมพ์คำอธิบายของมัน

![ตัวเลือกเปิดขึ้นเหนือ pane ของ agent ปุ่มลัดกับตัวกรองที่พิมพ์เข้าไปแคบลงเหลือ dev-server แล้ว Enter พิมพ์ herdr:dev-server(w2:p2) ลงใน prompt](./media/demo.gif)

- **สามคอลัมน์เชื่อมกัน** — space, แท็บของมัน และ pane ของแท็บ เป็นเส้นทางเดียวจากซ้ายไปขวาเสมอ
- **ปุ่มลัด** — `1`–`9` บนคอลัมน์ที่ใช้งานอยู่; กดสองครั้งถึง pane ใดก็ได้ในหน้าแรก
- **พิมพ์เพื่อกรอง** — ไม่มีโหมดค้นหา; เริ่มพิมพ์แล้วคอลัมน์จะแคบลง
- **ยืนยันได้ทุกระดับ** — `Enter` บน space ส่ง space, บน pane ส่ง pane
- **เริ่มจากที่คุณอยู่** — เคอร์เซอร์เปิดที่ space แท็บ และ pane ที่คุณเรียกมันขึ้นมา
- **รูปแบบของคุณ** — ค่าเริ่มต้น `herdr:{name}({id})`; เปลี่ยนเทมเพลตได้ด้วยการตั้งค่าบรรทัดเดียว

ตัวเลือกอ่านเซสชันผ่าน Herdr CLI และพิมพ์สตริงหนึ่งลงใน pane ที่เรียกมันเท่านั้น
มันไม่เคยส่ง prompt การทำงานกับ id เป็นหน้าที่ของ agent skill อย่างเป็นทางการของ Herdr
(`herdr --skill`); ปลั๊กอินนี้แค่สร้างตัวชี้

## การติดตั้ง

ต้องมี Node 18 ขึ้นไป

```sh
herdr plugin install navishachiku/herdr-pinpoint
```

ผูกปุ่มใน `~/.config/herdr/config.toml` แล้วโหลดใหม่ด้วย `prefix+shift+r`:

```toml
[[keys.command]]
key = "prefix+shift+p"
type = "plugin_action"
command = "herdr-pinpoint.open"
description = "pick a herdr target"
```

`prefix` คือ `ctrl+b` เว้นแต่คุณจะเปลี่ยนไว้

## ปุ่ม

| ปุ่ม | การทำงาน |
| --- | --- |
| พิมพ์ | กรองคอลัมน์ปัจจุบัน; รายการที่ตรงอันแรกจะถูกเคอร์เซอร์ชี้ |
| `↑` / `↓` | เลื่อนเคอร์เซอร์ในคอลัมน์ปัจจุบัน |
| `→` | เลือก: เปิดใช้รายการที่เคอร์เซอร์ชี้แล้วไปยังรายการลูก |
| `1`–`9` | เหมือน `→` สำหรับรายการที่มีหมายเลข; ใช้ได้เฉพาะตอนยังไม่พิมพ์อะไร |
| `←` | กลับไปคอลัมน์แม่ |
| `PgUp` / `PgDn` | เปลี่ยนหน้า (หน้าละ 9 รายการ) |
| `Ctrl-U` | ล้างคำค้น |
| `Enter` | พิมพ์รายการที่เคอร์เซอร์ชี้ลงใน pane ที่เรียกแล้วปิด |
| `Esc` | ล้างคำค้น; ถ้าว่างอยู่แล้วให้ปิด |

แต่ละคอลัมน์เก็บคำค้นของตัวเอง ป้ายหมายเลขจะปรากฏบนคอลัมน์ที่รับหมายเลข
ซึ่งคือคอลัมน์ทางขวาของรายการที่เปิดใช้ล่าสุด และจะหายไประหว่างที่กำลังพิมพ์คำค้น

## สิ่งที่ถูกพิมพ์

รายการแสดงด้วยชื่อและถูกส่งผ่านเทมเพลตผลลัพธ์:

| ระดับ | ชื่อ |
| --- | --- |
| Space | ป้ายชื่อ workspace |
| แท็บ | ป้ายชื่อแท็บ |
| Pane | ชื่อ pane (`herdr pane rename`), ไม่มีก็ `agent-name (kind)`, ไม่มีก็ชนิดของ agent, ไม่มีก็ `shell` |

ด้วยเทมเพลตเริ่มต้น การเลือก pane ชื่อ `dev-server` ใน `w2` จะพิมพ์:

```
herdr:dev-server(w2:p2) 
```

ข้อความถูกส่งผ่าน `herdr pane send-text` โดยมีช่องว่างต่อท้ายหนึ่งตัวและไม่ถูกส่ง
คุณจึงพิมพ์ต่อได้ คำนำหน้า `herdr:` มีไว้ให้คนอ่าน; id ในวงเล็บคือสิ่งที่ agent
ที่โหลด skill อย่างเป็นทางการของ Herdr ไว้จะทำงานด้วย ถ้าไม่มี skill นั้น สตริงนี้ก็เป็นแค่ข้อความ

## การตั้งค่า

การรันครั้งแรกจะเขียน `config.toml` ลงในไดเรกทอรีการตั้งค่าของปลั๊กอิน
(`herdr plugin config-dir herdr-pinpoint`):

```toml
output_template = "herdr:{name}({id})"
```

| โทเค็น | ค่า |
| --- | --- |
| `{name}` | ชื่อจากตารางด้านบน |
| `{label}` | ข้อความที่แสดงในคอลัมน์ เช่น `reviewer (codex)` |
| `{id}` | id ของ Herdr เช่น `w2:p2` |

## การพัฒนา

```sh
git clone https://github.com/navishachiku/herdr-pinpoint
herdr plugin link ./herdr-pinpoint
npm test
```

ป๊อปอัปอยู่ที่ `src/main.mjs`; สถานะของตัวเลือกอยู่ใน `src/model.mjs` และครอบคลุมโดย
`src/model.test.mjs` เป็น JavaScript ล้วน ไม่มีขั้นตอน build
